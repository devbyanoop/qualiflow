# QualiFlow

AI-native test automation platform — agentic generation, execution, healing, and triage of functional tests across web, mobile, and API, built in the open.

**Status:** Walking Skeleton complete (M0.1–M0.10) — ingestion, generation, human review, automation, and evidence hashing all work end-to-end against a real external app. Backend-only so far; no UI yet. See [the roadmap](docs/project/roadmap.md) for exactly what's proven and [the changelog](docs/project/changelog.md) for a one-line-per-milestone history.

**Docs:** [docs/](docs/) (MkDocs + Material site — run `mkdocs serve` to view locally).
