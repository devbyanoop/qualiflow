# Contributing

QualiFlow is Apache-2.0 licensed and built in the open from commit zero. Contribution guidelines fill in once the Walking Skeleton exists and there's real code to review against.

**Why the planning docs aren't in this repo:** the `Plan/` folder (product plan, business model, 24-month roadmap) is deliberately excluded from version control (see `.gitignore`). It holds pricing hypotheses, go-to-market strategy, and other material that doesn't need to be public for the code or this documentation site to be useful to contributors. What ships here — code, tests, and this guide — is the real, usable, open-source artifact.
