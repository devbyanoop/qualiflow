# QualiFlow

AI-native test automation platform — agentic generation, execution, healing, and triage of functional tests across web, mobile, and API, with manual-test sync, release intelligence, and audit-ready evidence.

Built in the open, as a LangGraph/MCP/RAG portfolio piece that grows into a real product. See [Roadmap & status](project/roadmap.md) for what's actually built vs. planned.

## Why this exists

Writing and maintaining test automation is slow, and locator breakage eats a large share of the effort that goes into it. QualiFlow generates real Playwright/Appium/pytest code (not a proprietary recorder DSL), reviewed by a human before anything automates, and heals broken locators in grouped pull requests instead of flooding reviewers one-fix-per-test.
